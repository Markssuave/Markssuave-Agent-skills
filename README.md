# Markssuave Agent Skills

A collection of 128 custom agent skills to supercharge your workflow!

## What are these?
These are specialized AI agent "skills" — pre-packaged sets of instructions, guidelines, and context that give AI agents specific roles, like a strict frontend designer, a rigorous backend tester, or a token-saving minimalist coder. You can install these into your own agent setup.
